## 一、项目简介

一款**俯视角 2D 生存游戏**。玩家操控角色在封闭地图中生存，抵御不断来袭的怪物。

核心体验是 **"在压力递增的环境中做出走位决策"** —— 何时进攻、何时退守、如何利用有限的空间活得更久。

玩家的核心操作**只有走位**：角色会**自动攻击**范围内的敌人，没有手动攻击键。

### 核心循环

```
玩家走位 → 自动攻击范围内怪物 → 击杀获得分数 → 时间推移怪物变强 → 生存更久获得更高分
      ↑                                                                    |
      └────────────────────────────────────────────────────────────────────┘
```

### 结束条件

- **结束**：玩家生命值归零 → 进入结算界面
- **胜利**：无（无尽模式，目标是拿到更高分数）

### 场景流程

```
Start（主菜单）──点击「开始游戏」──▶ Game（战斗）──生命归零──▶ GameOver（结算）
                                        ▲                          │
                                        └──────点击「重新开始」──────┘
```

## 二、操作说明

| 按键 | 功能 |
|---|---|
| **W / A / S / D**（或方向键） | 移动（八方向，已归一化，斜向不会更快） |
| **Esc** | 暂停 / 继续（弹出暂停面板，游戏时间冻结） |
| **鼠标左键** | 点击 UI 按钮（主菜单、暂停面板、结算界面） |

**攻击**：无需按键 —— 角色会自动攻击身边的敌人（有冷却，见下表）
**拾取**：走过去即可自动拾取掉落道具（触发器判定）

### 战斗参数（均在 Inspector 中可调）

| 项目 | 数值 |
|---|---|
| 玩家生命上限 / 初始生命 | 10 / 10 |
| 玩家移动速度 | 3（格/秒） |
| 玩家伤害 | 50 |
| 攻击范围 | 圆形触发器（跟随角色，半径 0.75 格） |
| 攻击冷却 `cd` / 攻击窗口 `lastingtime` | 1 秒 / 0.5 秒 |
| 受击无敌时间 `SetUndamagedTime` | 0.3 秒（期间每 0.1 秒闪烁一次） |

## 三、技术选型

| 方向 | 选择 | 理由 |
|---|---|---|
| 引擎 | **Unity 2022.3.62f3c1**（2D 模板） | 符合题目要求，2D 工具链成熟 |
| 物理 | **Rigidbody2D**（Dynamic + 圆形碰撞体） | 移动用 `rb.MovePosition`，怪物用 `rb.velocity`，击退/碰撞都由物理引擎处理 |
| 输入 | Unity 旧输入系统（`Input.GetAxisRaw` / `GetKeyDown`） | 需求简单，无需输入映射资产 |
| 相机 | **Cinemachine 2.10.7** 虚拟摄像机 + 自定义跟随脚本 | 视角锁定玩家，代码只负责每物理步同步位置 |
| UI | **uGUI**（Canvas / Text / Image / Button） | 与场景流程配合直观，便于做暂停与结算面板 |
| 场景管理 | 3 个场景（`Start` / `Game` / `GameOver`）+ Build Settings 顺序切换 | 流程清晰，主菜单与结算独立 |
| 资源加载 | `Resources.LoadAll`（敌人 / 道具 / 箭矢） | 无需额外配置即可按目录批量加载，便于"配置文件化"的道具表 |
| 数据驱动 | 组件化数值：`EnemyDefinition` / `PlayerDefinition` / `Weight` | 数值全部在预制体上配置，不改代码即可调平衡 |
| 全局状态 | `PublicDefinition`（静态分数）+ `GameManager`（难度成长） | 跨场景共享分数，难度曲线集中管理 |
| 掉落算法 | **累积权重表 + 空档区间**（加权随机） | 权重相对值即可，总掉率与物品分布互不干扰 |
| 帧率 | `Application.targetFrameRate = 60` + 关闭垂直同步 + 物理步长 `1/60` | 稳定 60 FPS，渲染与物理一一对应 |
| 打包 | Windows x86_64 独立版，Mono 脚本后端 | 构建快、迭代方便 |

| 题目要求 | 实现情况 |

## 五、进阶挑战（扩展系统）

题目提供 A~F 六个扩展系统（选做）。**本作品完整实现了扩展 A ，并部分实现了扩展 B 与扩展 E。**

### ✅ 扩展 A：道具 / 装备系统（完整实现）

- **7 种可拾取道具**（题目要求 ≥ 3 种），怪物死亡时按权重概率掉落：

| 道具 | 权重 | 效果 | 上限 |
|---|---|---|---|
| 血瓶 | 30 | 立即恢复生命（不超过上限） | — |
| 防护罩 | 30 | 免疫下一次伤害 | 一次性 |
| 愤怒 | 10 | 30 秒内伤害 ×2、移速 +3 | — |
| 吸血 | 8 | 累计受击次数达到 `100 − 等级×20` 时回复 1 点生命 | 3 级 |
| 强心脏 | 8 | 每级生命上限 +5（并同步当前生命） | 3 级 |
| 气量手套 | 8 | 每级伤害 +50 | 3 级 |
| 神速鞋 | 8 | 每级移速 +1 | 3 级 |

- **掉落由怪物死亡概率触发**：`Death` 组件在怪物死亡时调用权重抽样
  - 算法：累积权重表 + "空档"区间 —— `总掉率 = 物品总权重 / (物品总权重 + Fixed)`
  - 当前配置：权重和 102、`Fixed = 900` → **总掉率约 10.2%**，可只调 `Fixed` 一个数字改变总掉率，或调单个权重改变分布（两者互不干扰）
- **道具配置来自资源文件**：每个道具预制体上挂 `Weight` 组件（权重）与效果脚本（数值在 Inspector 可调），由 `Resources/Items/` 批量加载 —— 新增道具只需放入文件夹，**无需改代码**
- **UI 显示已获取状态**：吸血 / 强心脏 / 气量手套 / 神速鞋 / 防护罩 / 愤怒 均有对应的状态图标（1/2/3 级分别显示），获得与消耗即时刷新

## 六、难度曲线与刷怪规则

- **怪物在玩家视野之外生成**：刷怪器每 1 秒随机传送一次，并用摄像机视野判定，确保生成点始终在画面之外（玩家无法"蹲守出生点"）
- **生成器被碰到会逃离**：玩家主动靠近刷怪器时它会暂停刷怪并传送离开，避免被"堵住刷怪点"
- **难度随时间递增**（`GameManager`）：
  - 每 1 分钟：敌人生命 +50、击杀得分 +1
  - 每 3 分钟：敌人伤害 +1
  - 每波：本波生成数量 +5
- 玩家成长（道具）与怪物成长同时进行，形成"压力递增 + 逐步变强"的双向曲线
